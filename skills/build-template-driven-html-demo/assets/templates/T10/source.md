# T10 AI 交互工作台：来源与边界

## 参考来源

- Hume AI 产品主页：<https://www.hume.ai/empathic-voice-interface>
- Hume AI 官方开发文档：<https://dev.hume.ai/intro>

## 使用边界

本模板属于 **reference-only**。它只抽象 AI 语音与情绪产品常见的网页信息关系：会话工作区、波形、声音角色、模型配置、情绪指标和协作记录。这里没有使用 Hume AI 的产品代码、模型、API、数据或品牌资产。

本包的 HTML、CSS、JavaScript、中文文案、内联 SVG 图标、波形与 Mock 数据均为独立实现。没有复制第三方名称到示例界面，也没有复用徽标、截图、插画、字体、产品文案、声音、模型输出或专有组件。

## 运行与数据说明

- starter.html、tokens.css 与 interactions.js 无需安装依赖、启动服务、构建或联网。
- 最终生成时可将本地 CSS 与 JavaScript 内联为一个 HTML 文件。
- 页面不会访问麦克风、播放或合成真实声音、调用模型或上传数据。
- 会话、波形、情绪百分比、成员、声音角色、导出内容和分析结果均为虚构的本地 Mock，只用于验证网页交互与排版。
