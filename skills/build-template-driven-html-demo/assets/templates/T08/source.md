## 本模板如何参考

T08 只抽象通用设计规律：深色网页侧栏、浅灰工作区、抬升白卡、重叠彩色图标块、分级阴影、彩色面板标题和材质化输入反馈。它没有复制 Creative Tim 或 Material Dashboard 的品牌、Logo、截图、图片、字体、Material Icons、专有文案、HTML、CSS、JavaScript 或商业组件。

本目录中的 HTML、CSS、JavaScript、内联 SVG、中文文案和 Mock 数据均为本项目独立实现。运行时不加载 Bootstrap、图标库、在线字体或任何第三方依赖。

## Mock 数据声明

项目、客户、负责人、金额、阶段、日期、任务和指标均为 Codex 临时构造的匿名演示数据，只用于验证模板视觉与交互。它们不代表真实客户、真实合同或真实经营成果；生成客户 Demo 时应按已确认开发文档整体替换。

## 禁止复用

- 第三方商标、Logo、品牌名、截图、插画、图片、字体、图标和上游源码
- Material Dashboard PRO / 商业组件或许可范围不明的素材
- 客户真实姓名、联系方式、账号、合同信息或未脱敏业务数据
- CDN、Bootstrap、Material Icons、在线字体、远程 API、分析脚本或构建依赖
