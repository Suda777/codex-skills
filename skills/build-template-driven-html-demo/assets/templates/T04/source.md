## 独立实现声明

本模板包只抽象 Mazer 免费开源项目中可观察到的浅色导航、靛青主色、舒展留白、圆角卡片和友好后台节奏。HTML、CSS、JavaScript、中文文案、内联 SVG 图标、CSS 插画与 Mock 数据均为独立实现；没有复制上游源码、Logo、截图、插画、字体、品牌名称或专有文案。

模板不包含网络资源、外部依赖、构建步骤或服务端。样例数据均为匿名合成的本地 Mock，仅用于验证交互，不代表真实项目、人员、绩效或系统能力。

## 适配边界

生成客户 Demo 时保留轻盈、舒展、友好的组件语言；业务页面、字段、状态、计算、验证、确认规则、权限、文案和数据必须由已确认开发文档替换。
