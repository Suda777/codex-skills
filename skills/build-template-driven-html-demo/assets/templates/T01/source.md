# T01 来源与使用边界

## 参考来源

- 视觉参考：AdminLTE
- 官方演示：https://adminlte.io/themes/v4/
- 源码仓库：https://github.com/ColorlibHQ/AdminLTE
- 上游许可证：MIT（以仓库当前 `LICENSE` 文件为准）

## 本模板与参考来源的关系

T01 仅借鉴成熟后台网页常见的布局语言：深色左侧导航、浅色内容区、紧凑信息卡、筛选表格、详情层和操作反馈。当前目录内的 HTML、CSS 与 JavaScript 均为本项目重新编写，没有复制 AdminLTE 的代码、品牌标识、图片、页面文案或示例数据，也没有引入其依赖。

因此，生成客户 Demo 时应继续使用本目录的设计令牌、组件和交互约定，不要在运行时抓取或复制 AdminLTE 页面。若后续直接引入任何上游代码，必须重新核对并保留对应许可证及版权声明。

## Mock 数据

`starter.html` 和 `interactions.js` 中的机构名称、人员姓名、事项编号、日期、统计数字和办理动态均为 Codex 为模板交互演示临时构造的数据，不代表真实单位、真实项目或业务结论。生成正式 Demo 时，应按开发文档整体替换。

## 禁止复用

- 第三方 Logo、商标和产品名称
- 上游演示站中的图片、图标文件和文案
- 客户真实姓名、联系方式、账号或未脱敏业务数据
- 无法确认授权范围的网页截图与素材
