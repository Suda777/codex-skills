## 本模板如何参考

T07 只提炼通用设计规律：轻量侧栏、清晰边框、克制蓝色主操作、宽松间距、低阴影指标卡、现代数据表格和浅深色网页主题。它没有复制 TailAdmin 的品牌、Logo、截图、图标、插画、字体、专有文案、HTML、Tailwind 类名或 React 源码。

本目录中的 HTML、CSS、JavaScript、内联 SVG、中文文案和 Mock 数据均为本项目独立实现。模板不包含 Tailwind，不需要安装依赖、构建项目或联网运行。

## Mock 数据声明

任务、数据集、模型、成员、日期、质量分和运行指标均为 Codex 临时构造的匿名演示数据，仅用于验证模板视觉与交互。它们不代表真实客户、真实系统或真实 AI 结果；客户 Demo 应按已确认开发文档整体替换。
