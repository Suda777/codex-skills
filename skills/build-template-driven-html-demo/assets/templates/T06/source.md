## 本模板如何参考

T06 只提炼通用的视觉和交互规律：深蓝网页导航、蓝紫渐变、宽松留白、大圆角指标卡、柔和阴影、服务运营图表与响应式后台结构。它没有复制 Hope UI 的品牌、Logo、截图、插画、字体、专有文案、图标、组件代码或商业版功能。

本目录的 HTML、CSS、JavaScript、内联 SVG、中文文案和 Mock 数据均为本项目独立实现。运行时不请求参考网站，也不依赖任何第三方包。

## Mock 数据声明

页面中的区域、服务、工单、人员、日期、时长和统计值均为 Codex 临时构造的匿名演示数据，仅用于验证模板组件和交互。它们不代表真实客户、真实系统或真实业务成效；生成客户 Demo 时应按已确认的开发文档整体替换。
